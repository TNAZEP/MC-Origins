# Project identity

**Project and mod name:** Minecraft: Origins  
**Technical slug:** `minecraft-origins` (working default)  
**Future project namespace:** `origins` (reserved; no new gameplay content in 1.0)  
**First release:** 1.0 — Foundation Release

Minecraft: Origins is a continuation project built on the gameplay, feel, and behavior of Minecraft Beta 1.7.3, with a thoroughly modernized internal engine designed to support long-term development.

The audience is players who value Beta's character and developers who need a coherent foundation for later continuation work. The first release succeeds when a player can recognize Beta while a developer can work in a unified, modern, testable codebase.

1.0 establishes the foundation. Later feature releases may deliberately evolve the game, but no future feature is implied merely because the architecture can support it. Use the project name in build metadata, documentation, and distribution labels. Preserve Beta presentation; proposed visible branding changes beyond identification need deliberate scope decisions.

This is an independent project, not a claim of official Minecraft affiliation. The kit does not select a source-distribution license or include upstream game code.

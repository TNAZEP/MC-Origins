# Templates

Copy a template into its destination and fill it with actual observations. Placeholders are not proof of completion.

- [Session](SESSION.md): append to status/HISTORY and summarize in CURRENT.
- [Current status](CURRENT.md): replace current snapshot after reconciling repository state.
- [Milestone](MILESTONE.md): create a new bounded version when splitting/adding work.
- [ADR](ADR.md): record a consequential new decision or supersession.
- [Verification](VERIFICATION.md): reproducible command/manual evidence.
- [Issue](ISSUE.md): defect reproduction and closure.
- [Release](RELEASE.md): candidate checklist and artifact disposition.
